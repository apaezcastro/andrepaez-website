# Andre Paez-Castro Portfolio Website

This is the source code for my personal portfolio website, hosted on **GitHub Pages**. The site showcases my resume, projects, blog posts, and ways to connect with potential employers and collaborators.

## Features
- **About Me**: Overview of my background and skills.
- **Projects**: Interactive project cards with descriptions and links.
- **Blog**: Full posts on topics like Flask and Network Protocols.
- **Contact**: Links to GitHub, LinkedIn, and other social platforms.
