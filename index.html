Projects

Emotion Detection App

This application performs real-time emotion recognition by analyzing a user's webcam feed. It leverages a lightweight ONNX (Open Neural Network Exchange) model for efficient, client-side inference, paired with a minimal Flask backend to serve the application. The primary goal was to create a responsive tool that demonstrates the power of computer vision models running live on the cloud.

Technical Challenge: Developing for real-world environments highlighted the model's sensitivity to variable lighting conditions. This project served as a deep dive into the importance of data augmentation and the limitations of lightweight models compared to higher-parameter alternatives in non-ideal environments.

This project is deployed on Microsoft Azure and features a full CI/CD pipeline using GitHub Actions for automated builds and deployment.

Teak Custom Woodwork & Interiors

As the sole developer, I architected and deployed a professional digital presence from the ground up to serve as the primary lead-generation platform for a custom furniture business. Developed using Next.js, React, and Tailwind CSS, the site features a responsive showcase of high-end craftsmanship paired with a custom inquiry system.

Frontier Hunt (VR Survival Game)

Frontier Hunt is an immersive virtual reality survival experience developed specifically for the Meta Quest 3. Built using Unity and C#, the project focuses on high-fidelity spatial interactions and physics-based logic. It utilizes the Meta XR SDK and OpenXR to implement precise input mapping, including physics-based lantern toggles and environmental interactions.

The project emphasizes performance optimization for mobile VR hardware, leveraging efficient 3D asset management and atmospheric lighting to maintain the consistent high frame rates necessary for player comfort.
