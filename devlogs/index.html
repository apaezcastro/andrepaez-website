3. Deployment & Sideloading

Pre-Deployment: Enable USB Debugging in the Meta Horizon app (Developer Mode), connect via USB, and "Always allow" the RSA fingerprint prompt in-headset.
  1. Package using Android (ASTC) in Unreal.
  2. Navigate to your /Build/Android_ASTC/ folder.
  3. Run Install_MyFirstVRProject-arm64.bat to push to the headset.
  4. Open via App Library > Unknown Sources on the Quest.
